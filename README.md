## 🛠️ Portfolio Architecture & Technical Build

This portfolio is built from scratch using semantic HTML5, Bootstrap 5, modular vanilla CSS, and lightweight JavaScript interactions, avoiding the overhead of drag-and-drop website builders (like Wix or WordPress).

- **Structure:** Semantic HTML5 markup, structured for optimal accessibility and search engine visibility (SEO).
- **Styling:** A modular, Object-Oriented CSS (OOCSS) framework using vanilla CSS variables, transitions, and custom glassmorphic aesthetics.
- **Grid System:** Bootstrap 5 grid layout for absolute cross-device and mobile responsiveness.
- **Animations:** AOS (Animate On Scroll) library with custom staggered, lightweight scroll lifts.
- **Optimizations:** Zero inline styles, fully compiled font packages, optimized vector asset pointers, and zero-redundancy class definitions.
